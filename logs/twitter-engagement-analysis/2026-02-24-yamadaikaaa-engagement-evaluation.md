## 5. 最も効果の高い改善（優先度順）

### 優先度1: プロフィールの即時改善（現在4点 → 目標12点 / +8点）

**現在の致命的問題:**
プロフィール（名前「週5労働大嫌いドラゴン」、Bio「エロサイトこそクリーンに作るべきですね」）が発信テーマと完全に乖離している。リプライで1,000imp以上獲得しても、プロフィール訪問者がフォローに至らない。

**具体的アクション:**

1. 名前を変更: **「山田｜グルメスワイプ開発中🍜」** （profile-optimization案A推奨）
   - 「山田」= 人感、親しみ
   - 「グルメスワイプ」= アプリ名の認知蓄積
   - 「開発中🍜」= 応援したくなる未完成感 + 視覚フック

2. Bioを変更:
   ```
   飯探しに30分かけてたエンジニアが、3秒で店が見つかるアプリ作ってる🔥

   動画スワイプで「今日ここ行こ」が決まる
   ▸ 開発のリアル / グルメ / AIコーディング
   ▸ 3月ベータ版リリース予定

   店選びで消耗してる人、フォローしといて
   ```

3. 固定ポストを設置:
   ```
   グルメスワイプ、3月にベータ版出します

   「店選びに30分かけるのもう嫌だ」って人向けに作ってる
   動画スワイプで直感的に店が見つかるアプリ

   先行で使いたい人はLINE登録しといてくれ
   ベータ版の招待、LINEから先に送る👇
   ```

**なぜ最優先か:** プロフィールはファネルの入口。ここが壊れていると、他のどんな改善（リプライ、メディア等）も最終的なフォロワー獲得に繋がらない。

### 優先度2: リプライ量の大幅増加（現在7点 → 目標15点 / +8点）

**現在の問題:**
リプライの質は高いが量が不足。オリジナル平均40imp vs リプライ平均250impという6倍の差がある。

**具体的アクション:**

1. **1日のリプライ目標を5〜10本に設定**
   - 朝（7-9時）: 2-3本
   - 夕方（17-19時）: 2-3本
   - 夜（20-23時）: 1-2本

2. **リプライ対象リストを作成**（フォロワー1万以上、テーマ近いアカウント）
   - AIコーディング系: 5アカウント
   - グルメ系: 5アカウント
   - 個人開発系: 5アカウント
   - テーマ外でも伸びそうな大型アカウント: 5アカウント

3. **投稿から30分以内の即リプを最優先**
   - 通知をONにして大型アカウントの新着投稿をリアルタイムで把握
   - 初期リプはアルゴリズムで上位表示される（2026 Phoenix）

4. **リプライの型を3つに絞る**
   - 型1: 自分の体験を乗せる（最も効果的 → 1,304imp の実績あり）
   - 型2: 短いツッコミ + 本音（「負の遺産...」型）
   - 型3: 補足情報を加える（「8年やって思うのは〜」型）

**なぜ優先度2か:** 既にリプライで質の高い投稿ができることが証明されている。量を増やすだけで即座にimp合計が数倍になる最も費用対効果の高い改善。

## 7. 現在の強みと活かすべきポイント

改善点だけでなく、既に持っている強みも整理する。

### 強み1: リプライの文章力（最大の武器）

Top5投稿のうち4つがリプライ。「世代を跨いでも引き継がれる負の遺産...」（1,304imp）のような短く鋭いツッコミは、意図的に作ろうとしても難しい。AI非使用で自分の言葉で書いているからこそ出る「距離感の近さ」が武器。

### 強み2: 独自の視点と体験

エンジニア歴8年、元派遣・ニート経験、個人開発という独自のバックグラウンドがある。「新人と4年目にAIコーディングで同じ開発依頼したら、完成系イメージ持ってるかどうかで差がエグかった」のような実体験ベースの意見は、他のアカウントにはない。

### 強み3: 文体の確立

「俺」メインのカジュアルな語り口、「は？」「・・・」の使い方、自虐→ポジティブオチの構造が既に確立されている。これは0から作り上げるものではなく、山田のキャラクターそのもの。

### 活用の方向性

**この強みを活かす最善の方法 = リプライ量の増加。** 質は既にある。量を増やすだけで結果が変わる。

## 8. 注意事項

### やらないこと

- AI生成テキストへの切り替え: ユーザーが意図的に「プレーンテキスト手入力」で運用している。この真正性（authenticity）こそがエンゲージメントの源泉。AIで量産すると文体が均一化し、リプライの「距離感の近さ」が失われるリスクがある
- フォロワー購入やエンゲージメントグループ: 2026 Phoenixアルゴリズムはエンゲージメントの質を評価する。偽のエンゲージメントはペナルティの対象
- ハッシュタグ: 2024年12月以降、アルゴリズム非推奨が継続

### 測定指標

改善の効果を測定するために、以下を週次で追跡することを推奨:

```
1. 週間合計imp（オリジナル / リプライ / 引用RT 別）
2. プロフィール訪問数
3. フォロワー増減数
4. 平均エンゲージメント率（いいね + RT + リプライ / imp）
5. リプライ投稿数 / 日
```
