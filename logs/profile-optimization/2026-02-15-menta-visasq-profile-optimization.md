## 2. MENTA プロフィール原稿

### アイコン

- **必須:** 顔写真 or 信頼感のあるアイコン（MENTAではアイコンなしは致命的）
- 推奨: 清潔感のある顔写真。なければ、イラスト系アイコン（親しみやすさ重視）

### 表示名

```
山田｜AIでアプリ作る人 / エンジニア8年目
```

**設計意図:**
- 「AIでアプリ作る人」→ 2026年の最旬ワード。検索にも引っかかる
- 「エンジニア8年目」→ 経験年数で信頼感を担保
- MENTAの名前検索で「AI」「アプリ」「エンジニア」にヒット

### 自己紹介文（プロフィール本文）

```
はじめまして、山田です。
エンジニア歴8年、リードエンジニアとしてフロントエンド・バックエンド両方の
開発をやってきました。

現在は個人開発で「グルメスワイプ」というアプリを開発中です。
Cursor × Claude Code を使ったバイブコーディングで、企画からリリースまで
一人で進めています。

■ できること
- フロントエンド（React / Next.js / TypeScript）
- バックエンド（Node.js / Python / API設計）
- AI/LLM活用（ChatGPT API / Claude API / RAG構築）
- バイブコーディング（Cursor / Claude Code での実践的な開発）
- 個人開発の企画→設計→実装→リリースまで一気通貫サポート
- 受託開発の経験に基づく実務レベルのアドバイス

■ こんな方に選ばれています
- バイブコーディングでアプリを作りたいけど、一人だと不安
- Cursorを入れてみたけど、効率の良い使い方がわからない
- 個人開発を始めたいが、技術選定や設計で迷っている
- AIを活用した開発のやり方を実践レベルで教えてほしい
- プログラミング学習中だが、現場レベルのコードレビューを受けたい

■ メンタリングのスタイル
- レスポンスは原則24時間以内（平日は数時間以内を目指します）
- 「答えを教える」のではなく「一緒に考えて、自走力を上げる」スタイル
- 実際のコードを見ながら具体的にフィードバック
- 必要に応じてペアプログラミング（画面共有）対応

まずはお気軽にメッセージください。
「こういうアプリ作りたいんですけど…」レベルの相談でも大歓迎です。
```

**設計の根拠:**
- **冒頭で経歴**（信頼感）→ **個人開発の実績**（共感・ストーリー）→ **できること一覧**（判断材料）→ **ターゲット提示**（自分ごと化）→ **スタイル説明**（安心感）→ **CTA**（行動促進）
- MENTAのメンティーの40%がSNSを見て成約 → X連携は必須設定
- レスポンス速度に言及 → メンタースコア向上とメンティーの安心感の両方を狙う

### SNS連携（必須設定）

- **X（Twitter）**: グルメスワイプの開発アカウント（@GourmetSwipe）
- **GitHub**: プロフィールページ（ピン留めリポジトリにグルメスワイプ等を設定）

- 公募案件: 15,000円からスタート。ビザスクの平均が15,000円なのでまず実績を積む
- 指名案件: 25,000-30,000円。AI/バイブコーディングは需要に対して供給が少ないため強気設定可能
- フルサポート: 30,000円以上。ビザスクのスタッフ仲介で高単価にマッチング

**重要: 安く設定しすぎない**
> 手数料30%が引かれるため、5,000円設定だと手取り3,500円。
> シニアエンジニアの価値に見合わない単価は逆に信頼を下げる。
